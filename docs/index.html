Features

Small app, sharp edges

Everything it does, it does natively — no bundled runtimes, no background services you didn't ask for.

⌨️

Any hotkey you want

Ships with ⌘⇧G. Record a new combination in Settings — it re-registers on the spot and survives relaunches.

📋

Clipboard + auto-paste

The transcript always lands on your clipboard. With auto-paste on, it's also typed into the app that had focus when you started.

🗂️

History you control

Last dictations live in the tray menu — click to re-copy. Choose to keep anywhere from 1 to 500 entries, stored locally as JSON.

🔒

On-device recognition

Built on Apple's Speech framework and forced fully on-device when your Mac supports it. No vendor clouds, no telemetry, no accounts.

🎯

Focus-aware

OpenWhisper remembers which app you were in, restores focus, and stays out of the way. Cancel discards without a trace.

🪶

Genuinely lightweight

A single Swift binary with zero third-party dependencies. Tray-only, no Dock icon, no login requirements.

Build

No downloads. Compile your own.

There are no prebuilt binaries — on purpose. Every developer builds their own in about two minutes and gets a binary signed on their own machine.

# macOS 15+, Apple Silicon, Xcode 16 toolchain
git clone https://github.com/marcosoliveeira1/openwhisper.git
cd openwhisper

make app # compile, bundle, ad-hoc sign
open build/OpenWhisper.app

make test # 34 tests, Swift Testing
FAQ

Questions, answered honestly

Including the uncomfortable ones.

Where exactly does my audio go?

OpenWhisper uses Apple's Speech framework. When on-device recognition is available for Portuguese (Brazil) — which it is on modern macOS — the app forces requiresOnDeviceRecognition, so nothing ever leaves your Mac. On systems where on-device isn't available, it falls back to Apple's server-based recognition, the same path macOS built-in dictation uses. There are no third-party servers and no telemetry anywhere.

How does the auto-paste work?

On finish, the text is copied to the clipboard, focus returns to the app that was active when you started, and a synthetic ⌘V is delivered there via CGEvent. That's why macOS asks for the Accessibility permission the first time. Turn auto-paste off in Settings and the clipboard copy still works as a fallback.

Why does the default hotkey clash with Finder?

⌘⇧G is also Finder's "Go to Folder". Global hotkeys take precedence, so while OpenWhisper runs that Finder shortcut is taken. If you use it, record another combination in Settings — it takes ten seconds.

Which languages work?

Version 0.1 is configured for Portuguese (Brazil). The Speech framework underneath speaks many more locales — broadening language support is the next planned step.

Why isn't there a prebuilt download?

By design. There are no binary releases — every developer compiles their own with make app. You get a build you can inspect end-to-end, signed on your own machine, and you never have to trust a stranger's binary.

What's on the roadmap?

Next up: an optional AI correction pass through any OpenAI-compatible API (fixed locally, still opt-in) and multi-language support. Everything else — hotkey, history, auto-paste — is already in.
