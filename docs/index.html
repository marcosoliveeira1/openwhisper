Features

Dictation that stays out of your way

OpenWhisper is a tiny menu bar app built on native macOS frameworks. No Electron, no servers, no subscriptions — just press, speak and paste.

Global Hotkey

Default ⌘⇧G opens a floating panel and starts recording instantly — from any app. Change it to any combination in Settings.

Live Transcript

Watch your words appear in real time with a recording timer, in a clean centered panel with a soft frosted background.

Auto-Copy & Auto-Paste

Finished text lands on your clipboard and is pasted straight into the app that was focused when you started. Cancel discards everything.

History at a Click

Your last dictations live in the tray menu. Click any entry to copy it again. Keep between 1 and 500 entries — you decide.

Private by Design

Uses Apple's Speech framework with on-device recognition whenever your Mac supports it. No third-party servers, no telemetry.

Ridiculously Light

Native Swift app with zero third-party dependencies. Tray-only, no Dock icon, small binary. Built with SPM in one command.

Installation

Up and running in two minutes

Build from source with Swift Package Manager. Requires macOS 15+, an Apple Silicon Mac and Xcode 16+.

1

Clone the repository

Grab the source code from GitHub.

2

Build the app

make app compiles, bundles and ad-hoc signs OpenWhisper.app.

3

Grant permissions

Accept the microphone, speech and (for auto-paste) accessibility prompts. Start dictating with ⌘⇧G.

# Clone the repo
git clone https://github.com/marcosoliveeira1/openwhisper.git
cd openwhisper

# Build and bundle the app
make app

# Launch
open build/OpenWhisper.app

OpenWhisper uses Apple's Speech framework. When on-device recognition is available for the language (Portuguese–Brazil on modern macOS), it is forced fully local via requiresOnDeviceRecognition — nothing leaves your Mac. When on-device is unavailable, it falls back to Apple's server-based recognition, the same path macOS dictation uses. No third-party servers and no telemetry are involved.

When you finish a dictation, OpenWhisper copies the text, restores focus to the app that was active when you started, and synthesizes ⌘V there. This requires the Accessibility permission. You can toggle auto-paste off in Settings — the clipboard copy always works as a fallback.

Version 0.1 targets Portuguese (Brazil), which is what the recognizer is configured for. The underlying Speech framework supports many more locales — multi-language support is a planned improvement.

⌘⇧G is also Finder's "Go to Folder" shortcut. Global hotkeys take precedence, so that Finder shortcut stops working while OpenWhisper runs. If that bothers you, pick any other combination in Settings — Configurações → Atalho global.
